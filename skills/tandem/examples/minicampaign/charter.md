# Charter: minicampaign

Goal: answer "does build B beat build A on this box?" with a
publishable claim set. (A miniature: every mechanism of a real
campaign, none of the hardware.)

- Finish line: `claims.md` fully resolved and `claimgate` green.
- In scope: two data points, one citation.
- Non-goals: buying hardware, changing any running service.
- Primary sources (read before the plan is finalized): the build
  README, the vendor's documented run.
